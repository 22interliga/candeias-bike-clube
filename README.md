# Candeias Bike Clube

Repositório do site do Candeias Bike Clube (CBC).

## Publicação

Aguardando os arquivos originais do site para preservar as funcionalidades, a identidade visual azul e branca e a logomarca oficial.

Não publicar credenciais, dados pessoais de associados nem PIN administrativo como mecanismo de autenticação. A área administrativa real exige autenticação segura e regras de acesso no backend.
